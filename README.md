# DSH plugin catalogue

Public output of a private registry. This repository only ever holds the generated
contents of `site/` from `MrBlackD/my-dsh-plugins`:

- `index.json` — a format-1 DeepSeek Harness plugin index, generated from immutable release tags
- `icons/` — the icons it references

It contains no plugin source code. Do not edit by hand: the publish workflow mirrors
the generated catalogue here after validating it.

Catalogue URL: https://mrblackd.github.io/dsh-plugins-index/index.json
